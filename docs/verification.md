# 实施验证记录

日期：2026-09-16。

## 环境与结论

- macOS 27.0（26A428），Hammerspoon 1.1.1，单显示器，辅助功能权限已开启。
- 系统开启“按应用程序分组窗口”。实现对重叠缩略图计算可见区域，设置实际鼠标位置并发送悬停事件。
- 发现 AltTab 也使用 Command+Tab，曾抢占焦点。正式实机验收前已退出 AltTab；没有修改其配置。早期带 AltTab 的结果不计入最终验收。
- 退出 AltTab 后，两个 Chrome 同名空白窗口的 3 次切换成功；随后重新执行 20 次连续长按，20 次目标 ID 与实际焦点 ID 全部一致，调度中心均关闭。
- 短按回放触发应用切换，状态回到 idle；没有残留调度中心。
- 额外实机场景：Tab 后反引号返回、打开动画中提前松手均精确命中目标；Esc 取消后焦点保持在原窗口。
- 已安装到 `~/.hammerspoon/Spoons/MissionTab.spoon`，启动块已写入 Hammerspoon 配置并创建备份；已加载运行。

## 已知边界

- 自动实机按键由 Quartz 合成事件驱动；安装后用户实机反馈“短按和长按都正常”，真实物理按键基础交互已确认。
- 多屏、其他 macOS 版本、系统进程实际重启、Secure Input 的真实密码场景尚未实机验证；相关状态清理由模拟边界测试覆盖。
- AXPress 在早期调试中没有建立可靠的精确选窗证据，未用于正式确认路径。
- 完全被其他缩略图遮挡、没有安全可见区域的目标会取消，不猜测点击位置。
- 0.1.0/0.1.1 测试中的鼠标接管会结束会话；0.1.2 已按用户反馈修正为保留 Command 释放监听。系统产生的零位移 mouseMoved 不视为主动鼠标操作。
- AltTab 等工具不能同时接管同一个 Command+Tab。安装 MissionTab 不修改其他工具的登录启动设置。

## 复现

`README.md` 包含安装、停用及诊断命令。实机驱动为 `scripts/live-smoke.lua`，支持连续轮数和额外交互场景。驱动会保留所有计时器并捕获异步异常；鼠标接管或调度中心残留时中止，不继续发送下一轮按键。

## 评审修复

需求评审发现：在已发出打开请求、AX 尚未出现时取消，会过早结束会话。已改为有界等待并关闭随后出现的调度中心；同样覆盖 stop/start 清理，避免重复 toggle。补充回归验证后全部自动断言通过。

项目知识服务在本轮不可用，未宣称完成依赖外部 RULE 的完整规范评审；本地需求、实现、测试及用户实机反馈已核对。

## 0.1.1 导航顺序

按用户反馈改为顺时针 Tab、逆时针反引号，以最近使用的其他窗口为初始项。新增圆周顺序、初始选择与空间顺序分离、循环、单窗口及动画期间缓存输入的验证；81 项自动断言通过。原实机连续测试记录对应 0.1.0；本轮不重复无关的连续切换压力测试。

## 0.1.2

修正鼠标移动导致会话提前结束的问题，并支持在遗留调度中心中按 Command+Tab 退出。按用户要求直接交付，未运行测试或实机验证；此前断言和压力测试数量不代表本版本验收。
